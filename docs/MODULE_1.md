# Module 1 — Shoe Discovery and Selection (Lab 5)[cite: 16]

**Goal:** Allow users to discover shoes, explore colors, search by budget, and upload an outfit image for later analysis[cite: 16].

## Features & Assignments:
1. **[Athoy Roy] Browse Shoes by Category:** Browse shoes by gender-based categories and types (sneakers, formal, casual) retrieved from MongoDB via Cloudinary image URLs[cite: 13, 16].
2. **[Miftahul Islam Prangon] Color Exploration and Suggestions:** Explore available shoe colors and receive complementary color suggestions using the Color API[cite: 13, 16].
3. **[Diya Zerin] Budget-Based Shoe Search:** Search for shoes within a custom min/max budget range based on base prices stored in MongoDB[cite: 13, 16].
4. **[Khairul Islam Bhuiya] Outfit Image Upload:** Upload outfit images in JPG/PNG format with backend file type and size validation[cite: 13, 16].
